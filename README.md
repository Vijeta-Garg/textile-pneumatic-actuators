# Core Actuators vs Hand Massage

A static web page that shows four soft massage actuators next to the hand-massage technique each one copies:
effleurage, petrissage, tapotement and friction.

Open `index.html` in a browser. All clips autoplay, muted and looping. Click a clip to see it larger, and press Esc to close it.
